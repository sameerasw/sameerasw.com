# What's Changed
### Island
- Island blur _**[ I did not think it was possible ∑(O_O;) ]**_
- Customizable transparency
- Always neural expressive animation on expansion option
- Optimize the new island expand effects
- De-couple with notification pulse
- Move notification pulse to notification settings
- Disable new intensive effects by default for low end devices
- Island glow intensity control
- Fix silent notifications in island hub
- Fix battery icon colors
- Still island mode to allow dropping display Hz when inactive island
- Auto enable still island mode in power saving
- Fix island clipping by giving wider controls
- Live update icon extraction
- Recorder support
- Updated timer chip
- Split progressive blur settings for island
- Secondary island on right
- Fix navigation spam
- Fix silent persistent notifications
- Fix frozen bubbles

### Other
- Fix custom icon crash
- Fix liquid ripple and add to more places
- Fix shake for help
- Updated github based issue fields
- Report bugs from features
- New github issue labels and fields for reporting
- 24h clock for watchface
- voNR added to statusbar icon_blacklist
- Rename tomorrow's wallpaper to be Next
- Flashlight toggle off for MT devices
- More translatable text components
- Translations
