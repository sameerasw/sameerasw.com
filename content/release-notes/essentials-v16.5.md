# What's New?
- Battery information in Your Android
   > - Shizuku permission should be granted to the app in order for the details to be available
   > - These info might not be 100% accurate as most of them are gathered from battery dumpsys but I guess it's a different aspect.
   > - Some information such as the cycle count can be retrieved on supported Android 14 + devices with granting BATTERY permissions with Shizuku.
   Device support may vary. Only tested on a Pixel 9 Pro.
   - Battery health info for the battery freaks
   - Temperature monitoring
   - Cycle count
   - Charging stats
   - Predicted remaining time
   - Throttling status
   - Per-app battery drain summary
   - Per-system component based drain summary
   - CPU wakeups history
   
- Battery info can be accessed by long pressing the charging mode QS tile
   - Replaces the old bottom sheet while still providing the QS tile customizations
   
- New link actions UI
   - Material Expressive UI 
   - Navigation improvements
   
- Statusbar icon customization toggle
   - Mainly for the Samsung Good Lock users to avoid conflicts
   
- Bottom sheet UI improvements
- New translatable strings
- And a few more fixes and improvements
