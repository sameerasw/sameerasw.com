# What's New?
- Removed Dynamic Island settings and visibility options
- Fix ghost location hitbox
- Fixed overlapping UI elements
- Yandex Weather
- Refactored Yandex Weather error handling and attribution
- Fixed past hour/schedule showing "now" weather
- Added detailed moon phase tracking
- Added weather timeline feature
- Improved weather effects animations
- Fixed screensaver dismissal on swipe
- Added auto-animate option for screensaver timeline
- AM/ PM in screensaver
- Enhanced `RollingClock` animation
- Bumped app version to 1.2 (code 3)
- Island SDK for essentials
