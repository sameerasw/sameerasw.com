# What's New?
- Improve weather and particle visuals
- Adjust layering of weather effects
- Adjust weather effects intensity
- Improve app startup experience
- Improve automatic location based weather detection
- Switch to approximate location
- Custom weather icons
- Widgets
- Screensaver
- Full screen mode (swipe down)
- More weather units
- Lower min SDK level to 26 (Android 8)
- Compatibility mode for low end devices
- New settings UI and organization
- App onboarding
- New weather sources (Accuweather)
- Build flavors


* DevelopDevelop - more weather units, lowe sdk, improve rain and particle visuals, adjsut effect intensity, improve app startup, improve location, custom icons and more by @sameerasw in https://github.com/sameerasw/Overcast/pull/6
* Develop - Widgets, Screensaver, full screen mode, Compatibility mode and more by @sameerasw in https://github.com/sameerasw/Overcast/pull/7
* Develop - new settings UI, remove accurate location, onboarding, accuweather, build flavors, play billing by @sameerasw in https://github.com/sameerasw/Overcast/pull/10
