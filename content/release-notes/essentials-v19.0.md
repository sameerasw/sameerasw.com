# What's New?
- [Overcast](https://github.com/sameerasw/Overcast) integration - Weather is now separate
- HiLight controls
- Face unlock illumination
- Button remap multiple actions
- Lock screen shortcuts
- Privileged mode picker for shell integration
- Shizuku Next, Dhizuku & Porter support
- Extended media info on AOD wallpaper
- Dynamically hide media player on AOD
- Activity launcher and shortcut maker
- Keyboard shut up
- Hidden debugging and developer options support for Android 17 QPR1 & QPR3 beta

### Island
- Landscape notch
- Max item count
- Dynamically hide live updates in statusbar
- Expanded notification app icon
- Always available gestures
- Like and previous button controls
- Per-app notification filter
- Network Signal strength
- Island priority customization
- Hide island battery icon
- Island secondary bubble
- Fix timers and calls
- Decimal placement

### More
- Notification lighting DIY
- Camera HAL fixes for mediatek and more 
- Foldable camera profiles for Duo, Island, and Status Glance
- Duo & Island QS tiles
- Avoid screen locked security with extended unlock
- Accessibility system service restore with shut-up
- Combined DIY overlay actions menu
- Updated unsupported features and improved warnings
- Fix battery info for secondary user
- Fix progressive blur without statusbar
- Conscious gate animation fix
- Fix hotspot automation permissions
- Wallpaper ghost fixes
- Settings scroll fixes
- Overlay startup fixes
- And more improvements and fixes
- A tons of translations
- Features contributed by the community now mentions credits (WIP)
- Pick wallpaper for next day... but that's something for me to test :)
