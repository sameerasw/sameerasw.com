# What's New?
- Favorite QS tiles widget
   - Supports snap scroll on Android 17
   - New QS tile service handling for other intents
- Favorite features widget
   - Supports snap scroll on Android 17
   - Now available to older Android versions
- Improved battery info
   - Samsung support
   - Auto and manual stats reset
   - Per-app usage graph
   - Proper UID mappings
- Prevent flashlight related crashes on Mediatek (untested)
- More statusbar customizations (Not all OSs support them)
   - Clock position
   - More OEM specific tiles
- Shizuku watchdog support
- Restrict refresh-rate controls only to Pixels
- Fix some search results navigation
- Screen lock QS tile by @thekrdev
- WiFi & Bluetooth DIY automation triggers by @thomasborgogno
- Core refactor and reformat
- And more fixes and improvements
