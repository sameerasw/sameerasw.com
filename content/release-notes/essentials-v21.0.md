# What's New?
### Island
- Major island animation improvements
- Neural Expressive island
- New island player styles
- Hide media inside the player app
- Dismiss gesture customization and swipe to switch items
- Media bubble
- Open clock from time
- Per-app themed icons
- Enhance shadow pulse
- Time left for alarms
- Plugin show on update setting
- Statusbar aware island (Best for Pixels with low counts of icons)
- Animation and balancing improvements
- Expanded multi row title
- Notification images
- Resizable notifications
- Multiple media players
- Multiple live updates in island (Only with Overlap secondary bubbles)
- Secondary bubble count
- Improve notification action buttons
- Island calendar filter fix
- Fix tap to open
- Island calendar icon picker
- Ongoing events in island calendar
- Wider island width ranges
- Add delay to island dismiss on outside interactions
- Sound mode gesture silent mode with Shizuku
- RTL improvements
- Group notifications and multi lines in island
- Fix missing icon tints

### General
- Navigation 3 and UI redesign
- Foldable and landscape layout improvements
- More HiLight options
- Fix shizuku button remap auto start
- Power button remap
- Battery level based automations
- Fix unsupported features sheet scroll
- Keep last played apps in per-app vol control pop up
- Debug UI margins
- Fix clock position in blacklist
- Widget stack smart rotation
- Battery widget charging status fix
- How to use "Shut Up" help
- What is this footer
- Translations

### Project
- New PRs are now only approved for features after discussion on an issue.
