# What's New?
- Automations
   - Custom settings recording and actions
   - Change default keyboard by @thekrdev 
   - Volume level controls
- Rename SIM
- New link action bottom sheet by @Balajitechlabs  
- Link clean action by @Balajitechlabs  
- Button remap now shares the same automation actions
- Debugging tile long press options and customization
- Standby app bulk actions
- Are we there yet full screen alert
- Move maps power saving to display category and fix permissions
- Disable smart Pixels during screen recording (Notification detection)
- Prevent CTS while locked
- Fix crash on search 
- Fix flashlight fade animation lag
- Full code refactor and more improvements and fixes
