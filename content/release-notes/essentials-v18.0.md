# What's New?
- AOD wallpaper
- Essential search for Pixel search bar replacement
- Duo
- Secure QS tiles
- Improved web previews
- Apply on boot
- Improved in-app search
- Keyboard
   - Improved key accuracy
   - Justified bottom row
- Re-order favorite features
- Silent mode trigger without DND
- Shut up now reverts previous accessibility shortcuts
- Settings UI re-ordering
- Fix many empty search result navigations
- Improved developer options
   - Clear search history
   - Manual logs capture and sharing
- Improved in-app permission prompts
- Online help media
- Wider controls for CTS gesture area
- Link preview settings
- Motion blur slider
- Status glance [Experimental]
- Migrate to Compose progressive blur
- Import app update backups from ObtainX
- Zoom release note media
- Update Shizuku permission URL to GitHub
- A lot of feature wise toggles, permission fixes and improvements
- So many bug fixes

> With this big feature drop, There will be some busy days for me especially with the ending summer break and such. So frequent updates might not be expected as we are also I'm looking more into improving the app experience, functionality and the UI to be a much cleaner experience for the new and existing users.
Rather than being my playground for trying out whatever new things I find in Android that I think might be useful or **Essential** ... 
>
> Than being said, of course bug fixes will be prioritized and of course I will forget what I say 2 days later too. But gotta give some love to my other projects such as AirSync and MeDrop and also putting the Essential Watch face on play store for easier installation as well. Juuust a bit burned out lately so gonna try something fresh :) 
>
> Will see you around, Stay tuned <3
