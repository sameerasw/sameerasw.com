# What's New?
### Island
- AirSync in island
- Starlink island plugin
- Settings redesign
- Improve camera cutout detection
- Padding around
- Classic media player style
- Balancing improvements
- Battery symbols and color fixes
- Animate outline
- Fix navigation plugin glitches
- Backdrop blur availability info
- Fix swipe to dismiss glitches
- Island time priority adjustments
- Brief island overflowing items 
- Island presence indicator
- Island glow more customizations
- Clear all notifications and snooze (long press the expanded island icons carousel)
- Expanded dark mode warning
- Item based island interactions
- Optimize brief performance
- Expand island with intents
- Call support for google phone and meets
- Hide calendar events
- Multiple events support
- Island gesture hint toggle
- Improve dismiss animation
- Fix camera gap affecting padding
- Hiding island plugins
- islandSDK updates
- Chips for island app items

### More
- Text snippets
- Merge island and duo
- Fix freeze settings button when screen overflow
- Add missing freeze activity search
- Reset all settings
- Match colors with island in Duo
- Combine duo with secondary island bubbles
- Accessibility QS tile
- RTL in marquee support
- Security fixes
- Translations
- And a lot more fixes
