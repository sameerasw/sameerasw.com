# What's New?
- Island
   - Previous media button option
   - Combined notification settings
   - Weather effect haptics control
   - More notification catchup time options
   - Sound mode peek only on change option
   - Scaling improvements
   - Dynamic border colors
   - Fix squished icons
   - Alarm plugin
   - Tap on weather opens brief
   - Show items only on launcher
   - Animation improvements
   - More peek timeout options
   - Alignment hints
   - Calendar priority
   - Hide notification chat icon on lock screen
   - Delayed app change updates
- Weather
   - Separated from island
   - More sources
   - More effects
   - dedicated launcher shortcut
   - Open from weather in island
   - Weather experiments for testing
- Data sim and haptics QS tile
- Brightness adjustment action improvements
- Allow self select in app picker
- Overlay automations for Duo, Island and status glance
- Statusbar cmd fixes
- Open repo from details in your Android
- Haptic intensity control and improvements
- Simulate weather developer option
- Crash fixes
- And of course more minor stuff
