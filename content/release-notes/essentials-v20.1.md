# What's New?

### Island
- Notification hub
- Liquid like island animations
- Improved island animations, queue and UI
- Hide notifications, time and weather on island on lock screen
- Fix reddit notifications in island
- Island DND icon fixes
- Island settings re-organization and fixup
- Island notification settings cleanup
- Island clock formatting
- Fix battery icon colors in island
- Fix tests
- Island time chip
- Island time date suffix
- Island brief time formatting
- Fix notification switching in island hub
- Fix island navigation icon flicker
- Fix double notif in island
- Calls chip in island
- Themed app icons in island

### Other changes and improvements
- Hide statusbar
- Screenshot clean-up for all devices
- Shake for help
- Reset feature settings
- Fix memory related crashes with BT devices scan
- Space out shell commands to avoid spam
- Fix DIY modes list scrolling
- Hide CTS gesture in qs
- CTS automation trigger mode picker
- Fix networks with VPN for overlays
- A lot of sentry reported issues and crash fixes
- Updated a lot of feature descriptions
- Improve accessibility UI detection
- Translations
- And a lot more minor fixes and improvements
